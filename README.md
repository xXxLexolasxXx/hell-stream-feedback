# Hell Stream — обратная связь

Открытая площадка для идей и сообщений о проблемах в игре **Hell Stream**.

- [Поделиться идеей](../../issues/new?template=idea.yml)
- [Сообщить о проблеме](../../issues/new?template=problem.yml)

Для создания обращения нужен аккаунт GitHub. Обращения и вложения публичны: не публикуйте пароли, токены, личные фотографии и персональные данные. Перед приложением скриншота скройте лишнюю информацию.

Разработка игры и её исходный код находятся в отдельном закрытом репозитории. Этот репозиторий содержит только обратную связь и шаблоны обращений.
